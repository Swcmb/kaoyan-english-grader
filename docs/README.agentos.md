# AgentOS（艾嘿）：技能商店使用说明

AgentOS 的应用商店版本历史记录包含技能商店改版，以及“默认/已装”分类和自定义安装技能的能力。不同地区的 App Store 上架状态可能不同。

## 安装与登录

1. 在设备应用商店搜索 AgentOS 或 AIHEY（艾嘿）。
2. 确认开发者和应用信息与官方产品一致后安装。
3. 登录账号并进入应用首页。

如果当前地区的应用商店无法搜索到该 App，应以当地商店可用性为准，不要从不明来源下载安装包。

## 安装技能商店中的技能

1. 在应用中打开 **技能商店**。
2. 切换到 **默认** 或默认技能分类。
3. 浏览、搜索并打开技能详情。
4. 根据页面提示安装技能。
5. 切换到 **已装** 分类，确认目标技能已出现在列表中。
6. 返回对话并按技能说明发起任务。

应用版本历史记录说明技能商店分为默认和已装区域，并曾加入用户自定义安装技能的能力。具体按钮名称以当前版本为准。

## 自定义安装与本地 Skill 文件

公开的版本说明未明确给出自定义安装支持的文件格式、目录结构或导入协议。因此，不能确认 AgentOS 能直接导入本仓库的标准 SKILL.md 或 ZIP。

若当前应用提供“自定义安装”入口，请先查看界面提示的来源、格式和权限要求。仅当它明确支持标准 Skill 文件夹或压缩包时，才导入完整技能包，并验证 references/ 六份规则文件是否被一并读取。

## 安全检查

安装前检查技能提供方、授权范围和外部服务连接。对于会读写文件、访问账号或执行自动化任务的技能，先使用低风险任务验证。
