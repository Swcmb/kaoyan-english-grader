# AionClaw：手机端 Skill 市场安装

AionClaw 提供 iOS 和 Android App。应用商店介绍包含 Skill 技能市场、多专家协作和任务交付能力。

## 安装 App

- iPhone：从 [Apple App Store](https://apps.apple.com/cn/app/aionclaw-%E7%9C%9F%E6%AD%A3%E8%83%BD%E5%81%9A%E4%BA%8B%E7%9A%84ai%E9%BE%99%E8%99%BE%E5%8A%A9%E6%89%8B/id6775734154) 安装。
- Android：从 [Google Play](https://play.google.com/store/apps/details?id=com.abunda.aionclaw) 安装。

安装后登录账号并完成应用首次启动流程。

## 浏览和安装 Skill

1. 打开 AionClaw。
2. 进入 Skill 或技能市场入口。
3. 浏览分类或搜索所需技能。
4. 打开技能详情，检查用途、来源和使用条件。
5. 点击安装或添加。
6. 返回任务对话，描述希望完成的工作。
7. 检查 Agent 是否实际调用了该技能，并核对交付结果。

不同平台版本的入口文字可能不同，按当前 App 的技能市场页面操作。

## 本仓库 Skill 的导入边界

目前应用商店公开介绍能够确认 Skill 技能市场，但没有给出导入标准 SKILL.md 文件夹、ZIP 或 TAR.GZ 的完整步骤。本指南因此只记录市场安装流程，不把市场能力等同于任意自定义文件导入。

若 AionClaw 后续版本提供本地导入功能，导入本仓库时必须保留主 SKILL.md 和 references/ 六份规则文件，并验证题型引用可用。

## 验证

使用一个简单任务确认技能被调用，再使用需要专业判断的任务测试输出。使用本仓库时，至少分别测试英语一翻译与英语二大作文，检查分值和规则是否匹配。
