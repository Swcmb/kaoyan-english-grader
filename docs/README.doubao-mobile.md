# 豆包手机端：技能使用说明

豆包手机端主要用于调用当前账号可用的内置或已发布技能。自定义技能的创建和管理以电脑版工作任务模式为主。

## 手机端使用技能

1. 更新并打开豆包 App。
2. 登录与电脑版相同的账号。
3. 在当前对话或功能入口中选择已提供的技能；具体入口和可见技能随客户端版本、账号状态及灰度范围变化。
4. 根据技能提示提供任务材料和必要授权。
5. 查看技能返回的结果，并核对数据、引用和实际执行内容。

手机端没有稳定公开的通用本地 Skill 文件导入步骤。本仓库不能仅通过把 SKILL.md 发到普通聊天窗口，就视为已经安装为可自动触发的 Skill。

## 创建自定义技能

需要创建个人工作流或导入技能文件时，使用豆包电脑版的工作任务模式：

1. 打开豆包电脑版。
2. 进入工作任务模式。
3. 在侧边栏打开技能相关入口。
4. 使用创建技能的对话流程，或使用当前客户端提供的本地导入入口。
5. 保存后回到手机端，检查同一账号是否同步显示该技能。

技能同步情况以实际客户端为准。手机端如果只显示内置技能，使用手机版内的技能列表即可；创建入口仍使用电脑版。

## 本仓库的使用方式

若账号与客户端提供了个人技能导入能力，请在电脑版使用本仓库完整技能包，并确认 references/ 六份规则文件被一并保留。若没有本地导入入口，可以让豆包按英语一/二六类题型规则创建一个个人技能，并将本仓库的规则内容作为参考资料提供。
