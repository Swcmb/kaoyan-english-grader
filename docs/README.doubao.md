# 豆包工作任务模式：安装与创建 Skill

豆包工作任务模式支持用户创建自定义 Skill，也提供已上架技能的安装入口。个人用户使用和服务方通过开放平台上架是两条不同流程。

## 适用范围

本指南针对电脑版豆包的工作任务模式。手机端主要用于调用当前账号可用的技能，创建和管理技能以电脑版入口为准。

## 方式一：在豆包工作中创建个人技能

1. 更新并打开豆包电脑版。
2. 在侧边栏进入 **工作任务**。
3. 打开 **技能·连接器·伙伴**，进入技能区域。
4. 选择创建/新建技能入口。
5. 输入技能名称、用途、执行指令、输入要求和输出格式。
6. 保存后在技能列表中确认技能已经创建。
7. 返回工作任务对话，输入 / 或直接描述任务，选择该技能进行测试。

可以使用以下指令创建本项目的批改流程：

~~~text
请创建一个“考研英语 AI 批改”技能。

按照我提供的 SKILL.md 和六份 references 题型规则执行。
必须区分英语一、英语二的翻译、大作文、小作文。
每次批改都先判断考试类型和题型，再读取对应规则。
所有分数都是练习模拟评价，不得表述为官方阅卷结果。
输出中文讲解、逐句修改、完整修订稿和针对性复盘。
~~~

## 方式二：导入本地技能文件

部分客户端版本提供本地技能导入入口。若当前版本提供该入口：

1. 打开 **技能·连接器·伙伴**。
2. 进入技能管理或“我的技能”。
3. 选择导入本地技能/上传技能文件。
4. 上传包含主技能文件和辅助资料的技能包。
5. 导入完成后检查技能说明和引用资源，再保存启用。

本仓库需要完整保留 SKILL.md 与 references/ 六份规则文件。若客户端只接收单个文件或导入后没有保留子目录，不要把导入结果视为完整安装；改用“方式一”将规则内容整理到豆包自建技能中，或改用本仓库列出的标准 Agent Skills 工具。

豆包客户端菜单随版本调整，若没有本地导入入口，应使用对话式创建，不要假定 .agent/skills/ 是当前所有客户端都会自动扫描的正式路径。

## 方式三：开发者通过豆包开放平台上架

此流程面向服务方发布技能，供终端用户在豆包工作客户端的技能入口安装。官方流程要求企业资质认证并提交审核。

1. 登录豆包开放平台并完成企业资质认证。
2. 在控制台进入技能列表，选择创建技能。
3. 按平台技能规范准备 ZIP 技能包，上传资源。
4. 等待平台解析并完成包结构、内容和许可证校验。
5. 填写技能分类、评测报告链接和 5–10 条示例提示词。
6. 提交审核，在技能列表和版本列表中跟踪审核状态。
7. 审核通过并随商店发布后，终端用户可在豆包工作客户端的技能入口安装。

官方文档列出的 ZIP 限制包括：不超过 16 MB、最多 1024 个文件、单文件解压后不超过 2 MB、解压总量不超过 16 MB。此开发者上架流程不等同于个人用户导入本地技能。

## 验证

创建或导入后，先运行两个固定测试：

- “请按英语一翻译规则批改以下译文。”
- “请按英语二大作文规则批改以下图表作文。”

检查技能是否正确使用题型分值、错误分类和中文输出要求。若使用的是精简版自建 Skill，还需确认六类题型的规则均已迁移。
