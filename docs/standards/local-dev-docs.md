# 本机与私有项目文档规范

本规范适用于本机开发环境、私有仓库、团队内部系统、个人知识库和 Agent 工作区。公开项目文档遵循 [open-source-docs.md](open-source-docs.md)；GitHub Markdown 排版遵循 [github-content-writing.md](github-content-writing.md)。

## 目标与边界

本机文档帮助维护者安全、可重复地完成环境准备、开发、调试、部署、恢复和迁移。机器信息、内部地址、个人数据、凭据和组织信息不得因写入文档而自动成为可公开内容。

## 1. 按生命周期和读者规划文档

```text
project/
├── AGENTS.md
├── README.md
├── docs/
│   ├── architecture/
│   ├── development/
│   ├── operations/
│   └── decisions/
└── .local/
    ├── environment.md
    ├── secrets.example.md
    └── experiments/
```

| 文档类型 | 推荐位置 | 内容 |
| --- | --- | --- |
| Agent 规则 | `AGENTS.md` 或工具入口 | 范围、执行约束和验证要求 |
| 开发说明 | `docs/development/` | 依赖、构建、测试和调试 |
| 运维手册 | `docs/operations/` | 部署、回滚、备份和恢复 |
| 设计决策 | `docs/decisions/` | 背景、选项、决策和后果 |
| 本机环境 | 私有目录或本地知识库 | 主机路径、端口、设备和个人设置 |
| 实验记录 | 私有实验或研究目录 | 假设、参数、结果和复现方法 |

按项目规模选择目录，不机械创建所有目录。`.local/` 不会自动成为私有目录；使用版本控制时明确配置 ignore 并检查 Git 追踪状态。

## 2. 区分稳定事实、当前状态与计划

- **稳定事实：** 已验证且长期有效的约束、接口或架构。
- **当前状态：** 特定日期、机器、版本或配置下的实际情况。
- **计划：** 尚未执行的目标、方案或迁移步骤。
- **假设：** 需要实验或检查才能确认的判断。
- **历史记录：** 已被新状态替代的配置或故障过程。

记录当前状态时注明日期、版本、主机或环境。计划不得写成已完成，未经复现的原因不得写成确定根因。

## 3. 命令与环境必须可复现

开发指南记录操作系统、运行时与工具版本、安装/启动/构建/测试命令、必要环境变量、数据目录、端口、服务依赖、预期输出和健康检查。

命令应匹配目标 Shell。PowerShell、CMD、Bash 和 Zsh 的路径、引用和变量语法不同，不要将一种 Shell 的命令标记为通用命令。示例路径注明是占位路径还是真实路径。

迁移说明记录源路径、目标路径、数据量、校验方式和回滚方案。

## 4. 保护机密与个人环境信息

不得提交 API Key、访问令牌、密码、私钥、Cookie、会话文件、未授权数据或可直接访问私有服务的敏感入口。

文档只说明凭据名称和注入方式，示例使用 `YOUR_API_KEY` 等占位符。真实 `.env` 加入忽略规则，示例配置使用 `.env.example`。日志、截图和命令输出分享前完成脱敏。

机器名、个人用户名、绝对路径、局域网地址和设备序列号按必要性记录，优先放入私有文档。

## 5. 记录迁移、破坏性操作和回滚

影响数据、服务或开发环境的操作，应记录变更目标与范围、执行前状态和备份位置、精确命令和顺序、预期结果和检查方式、失败停止条件，以及回滚和数据恢复步骤。

磁盘迁移、容器卷迁移、数据库升级、代理配置和系统设置不以命令退出码作为唯一验收标准，还应检查数据、挂载路径、服务状态和应用读写行为。不可逆操作前先备份并验证恢复路径；风险无法确认时暂停操作并列出不确定项。

## 6. 控制重复和过期文档

同一事实维护一个权威来源，其他文档链接引用。修改配置、目录、端口、安装方式或脚本时同步更新对应 runbook。

高频变化内容记录最近核验日期。过期内容标记为历史或归档；实验记录保留假设、环境、参数、真实输出和复现方式，不将偶然结果上升为通用结论。

## 7. Agent 工作区规则

明确允许修改与禁止触碰的路径、执行前需检查的状态、破坏性命令的审批要求、任务成功标准、验证命令和失败回滚方式。

优先实施最小变更，只改完成任务所需文件。先检查现状，再执行操作；修改后运行对应测试并报告真实结果。

## 8. 共享或公开前检查

- [ ] 没有密钥、令牌、Cookie、个人信息或生产数据。
- [ ] 没有不必要的绝对路径、机器名或内部网络信息。
- [ ] 未验证假设没有写成事实。
- [ ] 命令的不可逆效果和生产影响已经说明。
- [ ] 截图和日志已经脱敏。
- [ ] 文档有唯一维护位置，旧版本已标记。
- [ ] 内容适合目标读者和访问范围。
- [ ] 公开发布时满足 [公开开源项目文档规范](open-source-docs.md)。
