# 腾讯元宝 App：技能安装与调用

腾讯元宝手机端支持通过技能入口浏览、安装和调用平台技能。当前公开的普通用户流程以技能市场为主。

## 安装技能

1. 将腾讯元宝 App 更新到当前版本并登录。
2. 打开 App 侧边栏。
3. 点击 **技能**。
4. 进入 **全部**，浏览分类或搜索关键词。
5. 打开目标技能卡片，查看功能说明。
6. 点击 **安装** 或 **使用**。
7. 回到对话中描述任务，元宝会根据需求调用已安装技能。

部分技能首次使用时需要完成账号登录、授权或绑定服务。确认授权目标与数据范围后再继续。

## 管理已安装技能

再次打开侧边栏的 **技能** 页面，查看已安装状态。若某项技能需要登录外部服务，优先在技能详情页完成授权，再回到对话中重试。

## 本仓库能否直接安装？

目前公开的元宝用户端流程没有提供任意本地 SKILL.md/ZIP 导入的明确步骤。元宝的技能市场安装与本仓库标准 Agent Skill 文件夹导入是两种不同能力。

因此，元宝 App 当前只能按平台技能市场的已有条目安装和使用。若要使用本仓库的完整批改流程，建议使用支持本地 Skill 导入的桌面 Agent 或千问办公、WorkBuddy 等渠道。

## 验证

安装后，在对话中提出与技能功能匹配的请求；若技能要求外部账号授权，完成授权后再测试。检查技能是否已经在技能列表中显示为已安装。
