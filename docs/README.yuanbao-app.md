# 腾讯元宝 App：技能市场安装与调用

腾讯元宝手机端提供技能入口，可浏览、安装和调用平台技能。当前公开的普通用户流程以技能市场为主。

## 安装市场技能

1. 更新元宝 App 并登录。
2. 打开 App 侧边栏中的 **技能**。
3. 进入 **全部**，浏览分类或搜索关键词。
4. 打开技能卡片，查看功能说明和提供方。
5. 按页面提示点击 **安装** 或 **使用**。
6. 返回对话并描述任务。

部分技能首次使用时需要登录外部服务或授权数据。确认授权目标和数据范围后再继续。

## 管理已安装技能

再次打开侧边栏的 **技能** 页面，检查安装状态。需要绑定服务的技能，先在详情页完成授权，再回到对话重试。

## 本仓库的导入边界

公开的元宝用户端流程没有明确说明普通用户可导入任意本地 `SKILL.md` 或 ZIP。技能市场安装与标准 Agent Skill 文件夹导入是不同能力。

需要本仓库完整批改流程时，选择支持本地 Skill 导入的桌面 Agent 或 QwenWork、WorkBuddy 等渠道。
