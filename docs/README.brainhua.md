# 脑花 App：沉淀与调用个人 Skill

脑花的 Skill 重点是把用户与 AI 协作过的流程、标准和方法沉淀为个人可复用能力。App Store 当前列出的版本为 iPhone App。

## 安装与开始使用

1. 在 iPhone 的 App Store 搜索“脑花 - AI 全能助手”，或打开下方 App Store 页面。
2. 安装并登录账号。
3. 在对话中选择一个有重复价值的任务，例如英语作文批改、资料归纳或固定格式报告。
4. 与脑花协作完成一次任务，并明确输入材料、处理步骤、判断标准和最终交付格式。
5. 检查输出符合预期后，再将该流程沉淀为 Skill。

## 将流程沉淀为 Skill

在完成一次高质量任务后，可以直接在对话中提出：

~~~text
请把刚才完成的流程沉淀为一个专属 Skill。

Skill 名称：考研英语 AI 批改
适用范围：考研英语一、英语二的翻译、大作文和小作文。
执行规则：先判断考试类型与题型，再按对应评分规则批改。
输出要求：中文逐句讲解、模拟评分、完整修改稿和针对性复盘。
边界：不得冒充官方阅卷，不得编造题目、图表或原文没有的信息。
下次遇到相同类型的任务时，优先调用这个 Skill。
~~~

保存前检查 Skill 的名称、触发场景、执行步骤和边界是否完整。完成沉淀后，下一次遇到相同任务时直接在对话中描述目标，或从应用提供的 Skill 能力中选择对应技能。

## 使用边界

脑花官方 App Store 说明支持调用和沉淀个人 Skill，但没有说明可以导入标准 Agent Skill 文件夹、SKILL.md 或 ZIP。因此，本仓库的标准技能文件不能直接视为已安装到脑花。

可以将本仓库的题型规则作为创建个人 Skill 时的参考资料，按应用实际支持的附件能力提供给它，再检查生成的 Skill 是否覆盖六类题型。

## 适用平台

当前 App Store 列表显示脑花 App 仅适用于 iPhone。iPad、Android 和桌面端的支持状态以应用商店的最新设备兼容信息为准。
