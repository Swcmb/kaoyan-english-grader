# 腾讯元宝 App：技能市场安装与调用

腾讯元宝手机端提供技能入口，可浏览、安装和调用平台技能。公开用户流程以技能市场为主。

## 安装与使用

1. 更新元宝 App 并登录。
2. 打开侧边栏中的 **技能**。
3. 进入 **全部**，按分类浏览或搜索关键词。
4. 打开技能详情，核对功能说明、提供方和授权要求。
5. 按界面提示安装或使用。
6. 返回对话提交匹配任务。

## 能力边界

公开用户端流程没有明确说明普通用户可导入本地 `SKILL.md` 或 ZIP。市场安装只有在本项目实际上架后才代表安装本项目。需要完整规则时，使用支持目录或单文件导入的桌面 Agent。

## 验收

检查技能状态，并分别测试英语一翻译和英语二大作文，确认完整规则、题型路由与模拟分值可用。

## 本仓库的 Skill 版本选择

技能市场只安装平台实际上架的条目；只有能够核验本项目的发布者和来源时，才能称为安装了本项目。应用内创建生成平台内部 Skill，需要将六类评分规则迁移并逐项核对，不能视为标准文件导入。若当前版本明确支持标准 Skill 目录或完整 ZIP，优先安装标准版；若只能导入单个标准 `SKILL.md`，使用独立完整版 `skills/kaoyan-english-grader-full/SKILL.md`。支持标准目录的平台也可安装完整版，但不推荐替代标准版。
