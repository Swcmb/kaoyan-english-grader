# AionClaw：手机端 Skill 市场

AionClaw 的公开应用商店页面介绍 iOS、Android 客户端和 Skill 市场。本页只记录市场安装流程。

## 安装与使用

1. 从 [Apple App Store](https://apps.apple.com/cn/app/aionclaw-%E7%9C%9F%E6%AD%A3%E8%83%BD%E5%81%9A%E4%BA%8B%E7%9A%84ai%E9%BE%99%E8%99%BE%E5%8A%A9%E6%89%8B/id6775734154) 或 [Google Play](https://play.google.com/store/apps/details?id=com.abunda.aionclaw) 安装。
2. 登录并完成首次启动。
3. 打开 Skill 或技能市场，浏览分类或搜索。
4. 查看技能详情、来源和使用条件。
5. 按页面提示安装，再回到对话测试。

## 安装边界

公开市场介绍未提供标准 `SKILL.md` 文件夹、ZIP 或 TAR.GZ 的导入步骤。只有本项目真实上架该市场后，市场安装才代表安装本项目。

## 验收

检查技能是否出现在目标产品的技能列表，并分别提交英语一翻译和英语二大作文测试。确认题型路由、分值、对应规则和输出结构正确。上传成功或保存成功不能替代实际调用验证。

## 本仓库的 Skill 版本选择

手机端若只是连接 Gateway 或远程 Agent，Skill 应安装在实际运行 Agent 的主机上。优先安装标准版并保留完整 `references/`；只有远程平台无法保留引用目录、但支持单个标准 `SKILL.md` 时，才使用独立完整版。手机端市场、对话添加和文件附件不等于远程主机已安装本项目 Skill。
