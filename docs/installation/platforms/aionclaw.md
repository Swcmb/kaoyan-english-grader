# AionClaw：手机端 Skill 市场

AionClaw 提供 iOS 和 Android App，公开应用商店介绍包含 Skill 市场、多专家协作和任务交付能力。

## 安装 App

- iPhone：从 [Apple App Store](https://apps.apple.com/cn/app/aionclaw-%E7%9C%9F%E6%AD%A3%E8%83%BD%E5%81%9A%E4%BA%8B%E7%9A%84ai%E9%BE%99%E8%99%BE%E5%8A%A9%E6%89%8B/id6775734154) 安装。
- Android：从 [Google Play](https://play.google.com/store/apps/details?id=com.abunda.aionclaw) 安装。

安装后登录并完成首次启动流程。

## 浏览和安装 Skill

1. 打开 AionClaw。
2. 进入 Skill 或技能市场。
3. 浏览分类或搜索目标技能。
4. 查看详情、来源和使用条件。
5. 按界面提示安装或添加。
6. 返回对话提交任务，检查 Agent 是否调用技能。

## 本仓库的导入边界

公开应用商店介绍能够确认 Skill 市场，但没有给出标准 `SKILL.md` 文件夹、ZIP 或 TAR.GZ 的导入步骤。本指南只记录市场安装，不将其描述为任意本地文件导入。

若后续版本增加导入能力，必须确认主文件和 `references/` 六份规则均被保留，并验证引用文件可读。

## 验证

先用简单任务确认技能触发，再测试英语一翻译和英语二大作文，检查评分和规则引用。
