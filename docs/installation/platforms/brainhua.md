# 脑花 App：创建与沉淀个人 Skill

脑花的 Skill 能力侧重将用户与 AI 协作过的流程、标准和方法沉淀为个人可复用能力。当前 App Store 列表显示其提供 iPhone App。

## 开始使用

1. 在 iPhone App Store 搜索“脑花 - AI 全能助手”，或打开官方页面。
2. 安装并登录。
3. 选择作文批改、资料归纳或固定格式报告等可复用任务。
4. 与脑花完成一次任务，明确输入、处理步骤、判断标准和交付格式。
5. 检查结果后，将验证过的流程沉淀为 Skill。

## 沉淀本仓库对应的工作流

完成任务后可在对话中提出：

```text
请把刚才完成的流程沉淀为一个专属 Skill。

名称：考研英语 AI 批改
适用范围：英语一、英语二的翻译、大作文和小作文。
执行规则：先识别考试类型和题型，再使用对应评分规则。
输出：中文逐句讲解、模拟评分、完整修订稿和针对性复盘。
边界：不冒充官方阅卷，不编造题目、图表或原文没有的信息。
下次遇到同类任务时优先调用。
```

保存前核对 Skill 名称、触发场景、执行步骤与边界。

## 与标准 Agent Skills 的区别

脑花公开 App Store 说明支持调用和沉淀个人 Skill，但未说明支持导入标准 Agent Skill 文件夹、`SKILL.md` 或 ZIP。因此，应用内沉淀不能视为已经安装本仓库标准 Skill。

可将本仓库规则作为创建个人 Skill 的参考，再检查生成内容是否覆盖六类题型。附件能力按当前 App 的实际支持情况使用。
