# 豆包工作任务模式：创建与导入 Skill

本指南面向电脑版豆包工作任务模式。个人创建技能、客户端本地导入和服务方通过开放平台上架，是三种不同流程。

## 创建个人技能

1. 更新并打开豆包电脑版。
2. 在侧边栏进入 **工作任务**。
3. 打开 **技能·连接器·伙伴**，进入技能区域。
4. 选择创建/新建技能。
5. 填写名称、用途、执行指令、输入要求和输出格式。
6. 保存并确认技能出现在列表中。
7. 在工作任务对话中输入 `/` 或描述任务，选择技能进行测试。

创建本仓库对应的流程时，可提供以下要求：

```text
请创建一个“考研英语 AI 批改”技能。

覆盖英语一、英语二的翻译、大作文和小作文六类题型。
先识别考试类型与题型，再使用对应评分规则。
所有分数均为练习模拟评价，不得表述为官方阅卷结果。
输出中文讲解、逐句修改、完整修订稿和针对性复盘。
不得编造题目、图表或原文没有的信息。
```

## 导入本地技能文件

部分客户端版本可能提供本地导入入口。若当前版本确实提供：

1. 打开 **技能·连接器·伙伴**。
2. 进入技能管理或“我的技能”。
3. 查找导入本地技能/上传技能文件入口。
4. 上传包含 `SKILL.md` 与 `references/` 六份规则的完整技能包。
5. 检查导入结果、引用文件和启用状态。

本仓库依赖引用文件。若客户端只接收单文件或未保留子目录，不要将其视为完整安装。可通过创建流程迁移规则，或使用支持标准 Agent Skills 的产品。

不要假设所有豆包客户端都会扫描同一个固定本地目录。

## 开发者通过开放平台上架

此流程面向服务方发布技能，供终端用户从豆包技能入口安装。平台文档要求企业资质认证并提交审核。

1. 登录豆包开放平台并完成企业资质认证。
2. 在技能列表中创建技能。
3. 按平台规范准备 ZIP 并上传资源。
4. 检查包结构、内容和授权信息。
5. 填写分类、评测报告链接和 5–10 条示例提示词。
6. 提交审核并跟踪审核状态。
7. 审核通过并随商店发布后，终端用户可从豆包工作客户端安装。

官方文档列出的 ZIP 限制：不超过 16 MB、最多 1024 个文件、单文件解压后不超过 2 MB、解压总量不超过 16 MB。该流程面向开发者上架，不等于普通用户本地导入。

## 验证

分别测试英语一翻译和英语二大作文，检查评分维度、分值和题型规则。使用自建精简版技能时，还要确认六类题型均已迁移。
