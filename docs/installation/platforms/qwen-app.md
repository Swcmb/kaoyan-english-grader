# 千问 App：手机端技能广场

千问 App 的工作助理提供技能入口，用户可从技能广场浏览和调用精选技能。手机端市场与桌面端 QwenWork 的本地文件导入能力分别管理。

## 浏览并安装技能

1. 在 iPhone 或 Android 手机上安装并更新千问 App。
2. 登录账号。
3. 进入 **工作助理 → 技能**。
4. 浏览推荐技能，或点击 **更多技能** 进入技能广场。
5. 按分类浏览或搜索关键词。
6. 打开技能卡片，按界面提示安装或调用。

## 使用已安装技能

在工作助理中选择已安装技能，或直接描述任务。执行复杂工作前提供必要资料、约束和交付格式，并检查结果中的数据和事实。

## 本仓库是否支持手机端直接导入？

千问 App 手机端公开资料确认了技能浏览和调用入口，但尚未确认普通用户可从手机文件系统导入任意第三方 `SKILL.md` 或 ZIP。桌面端 QwenWork 已公开本地技能包上传能力；两者不是同一界面。

需要使用本仓库完整规则时，优先使用桌面端 [QwenWork](qwenwork.md) 上传 ZIP，或选择支持标准 Agent Skills 的开发工具。

## 验证与官方资料

检查技能是否出现在列表，并通过匹配任务确认能否调用。市场中的同类英语写作技能不代表已安装本仓库六类批改规则。
