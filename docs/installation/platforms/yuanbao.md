# 腾讯元宝：技能市场与专属智能体

腾讯元宝提供技能浏览、安装和调用入口，也支持配置专属智能体。市场条目与个人智能体配置属于不同能力。

## 安装与使用

### 安装市场技能

1. 更新元宝 App 或电脑端并登录。
2. 打开侧边栏的 **技能**。
3. 进入 **全部**，按类别浏览或搜索。
4. 查看详情、提供方和授权要求。
5. 按页面提示安装或使用。

### 配置专属智能体

当前版本提供技能或知识库配置时，进入智能体创建/编辑页面，填写角色和任务指令，选择平台已有能力，保存后用新对话测试。

## 能力边界

配置专属智能体不等于上传标准 Skill 文件夹。普通用户是否能导入本地 `SKILL.md` 与引用目录，以当前产品入口为准。元宝开放平台属于服务方接入与审核渠道，不是普通用户即时安装命令。

## 验收

检查技能状态，并分别测试英语一翻译和英语二大作文，确认完整规则、题型路由与模拟分值可用。

## 本仓库的 Skill 版本选择

技能市场只安装平台实际上架的条目；只有能够核验本项目的发布者和来源时，才能称为安装了本项目。应用内创建生成平台内部 Skill，需要将六类评分规则迁移并逐项核对，不能视为标准文件导入。若当前版本明确支持标准 Skill 目录或完整 ZIP，优先安装标准版；若只能导入单个标准 `SKILL.md`，使用独立完整版 `skills/kaoyan-english-grader-full/SKILL.md`。支持标准目录的平台也可安装完整版，但不推荐替代标准版。
