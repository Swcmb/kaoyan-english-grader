# 腾讯元宝：技能市场与自定义智能体

腾讯元宝提供技能浏览、安装和调用入口。当前公开用户流程以平台技能市场为主，不能据此推断普通账号可导入任意本地 `SKILL.md` 文件夹。

## 安装市场技能

1. 更新元宝 App 或电脑端并登录。
2. 打开左侧边栏的 **技能**。
3. 进入 **全部**，按类别浏览或搜索。
4. 打开详情页，检查介绍、提供方和授权要求。
5. 按页面提示安装或使用。
6. 返回对话提交任务。

首次使用需要外部服务或数据授权时，先确认授权范围。

## 在专属智能体中配置平台能力

若当前版本提供技能或知识库配置：

1. 进入智能体创建或编辑页面。
2. 填写名称、角色和任务指令。
3. 在技能或知识库区域选择平台已提供的能力。
4. 保存并开启新对话验证调用。

该流程配置的是元宝已有能力，不代表可以上传本仓库的标准 Skill 文件和引用目录。

## 本仓库的使用边界

只有本项目真实上架元宝技能市场后，用户才能通过市场安装本项目。元宝开放平台是服务方接入渠道，需要按平台要求提交审核，不是普通用户的即时安装命令。

需要完整六类批改规则时，可选择 [QwenWork](README.qwenwork.md)、[WorkBuddy](workbuddy.md)、[Trae](README.trae.md)、[Qoder](README.qoder.md)，或 Claude Code、Codex、Cursor、OpenCode 等标准 Agent Skills 客户端。

## 验证与排查

检查目标技能是否显示已安装、首次授权是否完成，以及对话能否实际调用。技能未出现时刷新技能页并确认账号和客户端版本。

> **支持边界：** 本指南描述元宝技能市场与智能体能力，不代表普通用户可以直接导入本仓库标准 Skill 文件。
