# 灵犀·晓伴：AI 工具与技能中心

灵犀·晓伴由中国移动江苏公司推出。应用商店介绍包含 AI 工具与技能中心、第三方技能扩展、专属智能体和自动化任务能力。

## 安装

1. Android 用户可在小米应用商店搜索“灵犀·晓伴”，或通过产品官方提供的渠道获取。
2. 安装并登录账号。
3. 完成首次启动需要的权限和服务配置。

App Store 也存在灵犀·晓伴的 iOS 产品页面；具体可用地区和设备兼容性以相应应用商店为准。

## 浏览和启用第三方技能

1. 在应用主页或工具入口中打开 **AI 工具与技能中心**。
2. 浏览技能分类，搜索目标能力。
3. 打开技能详情，检查用途、来源、授权和使用条件。
4. 按页面提示添加或启用第三方技能。
5. 返回对话或对应的智能体场景，提交与技能用途匹配的任务。
6. 在使用记录中检查运行情况。

## 创建专属智能体

产品介绍还提及自定义创建个人专属智能体及接入第三方智能体。若需要组合多项能力，可进入 AI 创作与智能体专区，按页面提示创建智能体，配置角色、目标和可用能力，再用独立任务测试。

## 本仓库 Skill 的导入边界

目前公开应用商店信息确认了第三方技能扩展能力，但没有列出标准 Agent Skill 的 SKILL.md、ZIP 或 TAR.GZ 文件导入步骤。因此，这里只记录应用内技能中心的安装和使用方式，不声称可以直接上传本仓库文件。

如当前版本的技能中心新增本地文件导入入口，导入前应确认它能够保留 SKILL.md 与 references/ 的目录关系；只导入主文件无法加载本项目六份题型规则。
