# 灵犀·晓伴：工具与技能中心

灵犀·晓伴由中国移动江苏公司推出。应用商店介绍包含 AI 工具与技能中心、第三方技能扩展、专属智能体和自动化任务能力。

## 安装与登录

1. Android 用户可在小米应用商店搜索“灵犀·晓伴”，或使用产品官方渠道。
2. 安装并登录账号。
3. 按首次启动流程完成必要权限与服务配置。

App Store 也提供 iOS 产品页面。地区可用性和设备兼容性以相应商店为准。

## 使用第三方技能

1. 在主页或工具入口打开 **AI 工具与技能中心**。
2. 浏览分类并搜索目标能力。
3. 打开详情，检查用途、提供方、授权和使用条件。
4. 按页面提示添加或启用技能。
5. 返回对话或对应智能体场景提交任务。
6. 在使用记录中检查运行状态。

## 创建专属智能体

产品介绍提及个人专属智能体和第三方智能体接入。需要组合能力时，可进入 AI 创作或智能体专区，按页面提示配置角色、目标和可用能力，再用独立任务验证。

## 本仓库的导入边界

公开应用商店信息确认第三方技能扩展能力，但未提供标准 Agent Skill 的 `SKILL.md`、ZIP 或 TAR.GZ 导入步骤。因此，本指南记录应用内技能中心，不声称可以直接上传本仓库文件。

若当前版本新增本地导入入口，先核对文件格式和目录要求，并验证 `SKILL.md` 与 `references/` 六份规则是否完整保留。
