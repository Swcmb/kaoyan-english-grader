# 腾讯元宝：技能市场安装与使用

腾讯元宝面向普通用户提供技能浏览、安装和调用入口。当前公开用户流程以技能市场中的服务技能为主，不能据此推断普通账号可以导入任意本地 SKILL.md 文件夹。

## 安装市场技能

1. 将腾讯元宝 App 或电脑端更新到当前版本并登录账号。
2. 打开左侧边栏中的 **技能**。
3. 进入 **全部**，按类别浏览或搜索技能名称。
4. 打开目标技能卡片，查看介绍、服务提供方和需要授权的权限。
5. 点击 **安装** 或 **使用**。
6. 安装后返回对话，直接描述任务；也可以再次打开技能卡片，按页面提示启动。

部分技能第一次使用时会要求绑定服务账号或授权外部数据。先检查授权范围，再确认启用。

## 在专属智能体中使用技能

如果当前版本的智能体创建流程提供技能/知识库配置：

1. 进入智能体创建或编辑入口。
2. 填写智能体名称、角色和指令。
3. 在技能或知识库配置区域选择可用的技能与资料源。
4. 保存智能体，并在新对话中测试它是否能调用对应能力。

这个流程配置的是元宝平台已经提供的能力。普通用户侧尚无官方公开说明能够直接把本仓库的 SKILL.md 和 references 目录上传为一个通用 Agent Skill。

## 本仓库的使用边界

本仓库没有元宝技能市场的上架条目时，无法通过元宝的技能市场直接安装本项目。若需要使用完整考研英语批改流程，请选择支持本地 Skill 导入的 QwenWork、WorkBuddy、Trae、Qoder，或使用 Claude Code、Codex、Cursor、OpenCode 等标准 Agent Skill 客户端。

元宝开放平台属于服务方接入渠道，需要按平台要求提交能力并通过审核。该路径适用于计划发布并运营元宝服务技能的团队，不是本仓库用户的即时安装命令。

## 验证与排查

- 在技能页面检查目标技能是否处于已安装状态。
- 回到对话中提出与技能描述匹配的任务。
- 若技能涉及外部服务，完成首次授权后重试。
- 若没有出现目标技能，刷新技能页面并确认当前账号/客户端版本。
