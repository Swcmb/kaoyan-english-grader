# 千问 App：手机端 Skill 安装与调用

千问 App 的工作助理提供技能入口，用户可以从技能广场浏览并调用精选技能。手机端技能市场与桌面端千问办公（QwenWork）的本地文件导入能力分开管理。

## 在手机端浏览并安装技能

1. 在 iPhone 或 Android 手机上安装并更新千问 App。
2. 登录账号。
3. 进入 **工作助理**。
4. 点击 **技能**。
5. 浏览当前推荐技能；点击 **更多技能** 可进入技能广场。
6. 按分类浏览或搜索关键词。
7. 打开技能卡片并按界面提示安装或调用。

## 使用已安装技能

在工作助理中选择已安装技能，或在对话中直接描述目标任务。执行复杂工作前，提供必要资料、边界和交付格式；对结果中的文件、数据和事实进行检查。

## 本仓库能否直接导入？

千问 App 手机端公开资料确认了技能浏览和调用入口，但尚未确认普通用户可以从手机文件系统导入任意第三方 SKILL.md/ZIP。桌面端 QwenWork 已公开支持上传本地技能包；这不是同一个产品界面。

要使用本仓库的完整技能，优先在桌面端 QwenWork 通过扩展 → 技能 → 添加 → 上传技能导入 ZIP，或在支持标准 Agent Skills 的开发工具中安装。

## 验证

手机端选中某项技能后，先用简单任务确认触发，再提供真实工作内容。对于考研英语批改项目，需确认技能包含六类题型规则；仅能调用技能市场里的同类写作能力，不代表安装了本仓库。
